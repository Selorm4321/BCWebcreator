## 1. Keyword Formula

Local service keywords follow a predictable pattern:

```
[service] + [city/region]
[service] + "near me"
[service] + "BC" / "Canada"
"affordable" + [service] + [city]
"best" + [service] + [city]
```

**Examples for web design:**
- web design Vancouver
- web design Abbotsford
- website designer Fraser Valley BC
- affordable website Langley
- small business website Chilliwack

## 2. Priority Tiers

Target keywords in this order based on competition and volume:

| Tier | Type | Example | Why |
|---|---|---|---|
| 1 | Primary city | "web design [city]" | Highest volume, hardest |
| 2 | Nearby cities | "web design [suburb]" | Lower competition, faster wins |
| 3 | Region | "web design [region] BC" | Broad coverage |
| 4 | Long-tail | "affordable website for [industry] in [city]" | High intent, easy to rank |
| 5 | Question | "how much does a website cost in [city]" | Blog/FAQ content |

**Strategy for new sites:** Start with Tier 2 and 3 (lower competition), build authority, then compete for Tier 1.

## 3. Page-to-Keyword Mapping

Each page should own one primary keyword cluster. Never target the same keyword on two pages.

| Page | Primary Keyword | Secondary Keywords |
|---|---|---|
| Homepage | [service] [primary city] | [service] [region], [service] BC |
| Location: City A | [service] [City A] | affordable [service] [City A], [service] near [City A] |
| Location: City B | [service] [City B] | [service] [City B] small business |
| Service page | [specific service] [city] | [specific service] near me |
| Blog post | question keyword | informational long-tail |

## 4. Title and Meta Description Formulas

### Title tag (50–60 characters)
```
[Primary Keyword] | [Differentiator] | [Brand Name]
```
Examples:
- `Web Design Abbotsford | Affordable & Local | BC Web Creator`
- `Web Design Fraser Valley BC | Custom Websites | BC Web Creator`

### Meta description (120–155 characters)
```
[Brand] [verb phrase with primary keyword]. [Value prop]. [CTA with price or differentiator].
```
Example:
- `BC Web Creator builds affordable, custom websites for Abbotsford small businesses. Local SEO included. Starting at $1,200. Get a free quote.`

### H1 (on-page heading)
- Must contain the primary keyword
- Can be longer and more descriptive than the title tag
- Example: `Web Design Abbotsford — Built for Local Business`

## 5. Competitor Research Method

To identify what keywords competitors rank for:

1. Google the primary keyword (e.g., "web design Abbotsford")
2. Note the top 3 organic results (not ads)
3. For each competitor, check:
   - Their page title and H1
   - Their meta description
   - How many location pages they have
   - Whether they have a blog
4. Look for gaps: cities or services they don't cover → target those first

**Free tools:**
- Google Search (incognito mode) — check who ranks
- Google Search Console (your own site) — check what queries you already appear for
- Google Keyword Planner (free with Google Ads account) — check search volumes
